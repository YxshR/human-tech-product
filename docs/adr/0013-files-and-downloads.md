# ADR-0013: Files, signed downloads and access logging

Status: accepted

- Storage sits behind a port (`@humantech/storage`) with local-disk and S3 drivers; selected by `STORAGE_DRIVER`.
- Uploads are proxied through the API so size, content type and SHA-256 are checked before anything is stored (`MAX_UPLOAD_BYTES`, default 10 MB; PDF/JPEG/PNG for documents; CSV for imports).
- Downloads are HMAC-signed links valid for 60 seconds (`FILE_SIGNING_SECRET`), issued only after the normal permission and scope checks. Every access is recorded in `file_access_events`.
- Payslip PDFs are generated by the worker (Latin script, amounts prefixed `INR`); exports and import result files are stored files (exports carry an expiry).
- **Not included:** malware scanning. Put a scanner in front of the bucket before accepting files from untrusted users.
